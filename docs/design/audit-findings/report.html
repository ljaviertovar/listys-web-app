Regla

El DS documenta cada componente con sus propias variantes, medidas y estados según la implementación shadcn correspondiente. No define una escala universal ni asigna píxeles a partir del nombre de la variante.

Button, Input, Select y Form

  • Button: variantes y tamaños tomados de la API shadcn pertinente al paquete/base del proyecto.
  • Input: documentar según su propia API; no hereda tamaños de Button.
  • Select: documentar Trigger y opciones según su API; no hereda tamaños de Button ni Input.
  • Form: composición de campos, labels y mensajes; no añade una escala propia.
  • Extensiones locales: se muestran aparte, por ejemplo el filtro especializado de Trips.

La documentación oficial tiene bases de UI diferentes y no permite asumir una misma escala entre componentes. Hay que cotejar cada variante con la implementación instalada antes de definir el preview.

Hallazgo DS-001

El catálogo todavía debe reemplazar las muestras antiguas con previews fieles a cada API y separar las extensiones locales de las variantes nativas. La implementación de la app no se ha cambiado.
